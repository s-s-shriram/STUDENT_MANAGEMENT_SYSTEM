# Student Management System (React)

This is a simple **Student Management System** built using **React**.

## Features
- Add student details (Name, Roll Number, Department)
- View student list
- Delete student records
- Simple and clean UI

## Tech Stack
- React JS
- JavaScript (ES6)
- HTML/CSS (inside React JSX)

## How to Run
If you want to run locally:
1. Make sure Node.js is installed
2. Install dependencies:
```bash
npm install
```
3. Start the project:
```bash
npm start
```
The project will open in your browser at http://localhost:3000
